# Corporate Finance II

Interactive slides for Corporate Finance II (PGDM, Term III), IMT Hyderabad. The site follows the same design as the CF1 site.

Open `index.html` for the course page. Each module links to a slide deck:

| Module | Sessions | Deck |
|---|---|---|
| 1. Financial Statements and Planning | 1 to 4 | `financial-statement-analysis.html` |
| 2. Capital Structure and Firm Value | 5 and 6 | `capital-structure.html` |
| 3. Leverage | 7 | `leverage.html` |
| 4. Dividend Policy | 8 and 9 | `dividend-policy.html` |
| 5. Working Capital Management | 10 to 12 | `working-capital.html` |

Each deck is a single self-contained HTML file. Move with the arrow keys or swipe; press O for the slide list and F for full screen. Slides fit the screen on laptops and projectors and scroll on phones.

Formulas and the Prufrock example follow Ross, Westerfield, Jaffe, Jordan and Shue, *Corporate Finance*, 14th edition. The 2019 Prufrock income statement and share price are constructed for teaching; the book gives only 2020.

To publish, enable GitHub Pages for this repository (Settings → Pages → deploy from the `main` branch, root folder).
